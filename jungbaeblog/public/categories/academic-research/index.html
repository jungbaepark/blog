🧠 Attentional Control for Time-Series Data (Master's Thesis)

Overview My Master’s thesis research at KAIST exploring attentional control methods for time-series data classification and synthesis. This work investigated how attention mechanisms can improve deep learning models’ ability to process sequential data. Research Focus Developed novel attention-based approaches for: Time-series Classification: Identifying patterns and categories in sequential data Time-series Synthesis: Generating realistic sequential data with desired characteristics Key Contributions EEG Signal Classification Applied reinforcement learning for adaptive EEG signal processing Solved the memory-based vs. memoryless trade-off problem Publication: Jungbae Park, *Sang Wan Lee - “Solving the Memory-based-Memoryless Trade-off Problem for EEG Signal Classification” (IEEE SMC 2018, Oral) Attention Mechanisms for Sequential Data Investigated how attention can focus on relevant time steps Balanced model capacity with interpretability Applications in neuroscience and signal processing Tech Stack Deep Learning: LSTM, Attention mechanisms Signal Processing: EEG analysis, time-series processing Frameworks: TensorFlow, PyTorch Applications Brain-Computer Interfaces (BCI) Medical signal analysis Sequential pattern recognition Temporal data synthesis Period March 2017 - February 2019 ...

🤖 Multi-Agent Cognitive Policy Learning through Competition

This work was inspired by how humans develop cognitive abilities through social interaction and competition. Research Question Can AI agents develop sophisticated cognitive strategies by competing with each other, similar to how humans learn through social competition and cooperation? Key Contributions Developed multi-agent RL framework for cognitive policy learning Demonstrated emergence of complex behaviors through agent competition Explored connections between computational models and cognitive science Recognition Best Paper Award: 2016 Fall Korea Intelligent Information System Conference ...
