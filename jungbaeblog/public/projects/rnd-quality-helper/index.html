Overview#

At Bucketplace (오늘의집) AIL, built a Claude Code plugin that orchestrates 17 specialized agents and 14 skills to automate R&D workflows—from research and planning through implementation, code review, and verification. A team-level PoC that demonstrates multi-agent orchestration for developer productivity.

Key Achievements#

  • 17 Specialized Agents: Covering research (codebase, convention, history, API, web, academic), planning (feature, refactor, migration), review (logic, security, architecture, quality, performance), and verification (functional, regression, integration)
  • 14 Skills: Workflow orchestration, plan change detection, multi-persona review, verification (quick & full), and self-review at each phase
  • Cross-Model Review: Parallel multi-persona code review using Claude, Codex, and Gemini simultaneously with 3-layer defense
  • Structured Workflow Pipeline: Research → Aggregate → Plan → Implement → Verify → Iterate

Technical Approach#

Multi-Agent Orchestration#

Each agent is a specialized subprocess with its own system prompt, tool access, and domain expertise. Agents are launched in parallel where tasks are independent and sequentially where dependencies exist.

Cross-Model Multi-Persona Review#

The review system runs multiple specialized reviewers (logic, security, architecture, quality, performance, positive) in parallel across different LLM backends, aggregating findings with confidence-based filtering.

Workflow Pipeline#

graph LR
    A["Research\n(parallel)"] --> B["Aggregate\n(prioritize)"]
    B --> C["Plan\n(planner+critic)"]
    C --> D["Implement\n(+review)"]
    D --> E["Verify\n(test+check)"]
    E --> F["Iterate\n(feedback)"]
    F -.->|feedback| C

The /workflow skill coordinates a 6-phase pipeline:

  1. Research (parallel): Select relevant researchers based on task scope
  2. Aggregate: Synthesize findings into prioritized brief
  3. Plan: Choose planner by task type, then self-review
  4. Implement: One logical change at a time with checkpoint reviews
  5. Verify: Run tests + specialized verifiers in parallel
  6. Iterate: Adaptive feedback loop back to the smallest relevant phase

Enterprise Plugin Ecosystem#

Part of a broader initiative to build a company-wide Claude Code plugin marketplace at Bucketplace:

  • Plugin distribution via shared directory structure (~/claude-marketplace/plugins/common)
  • Team-specific plugins alongside common plugins
  • Internal guide for enterprise adoption published on Notion

Notion Integration#

Plan documents can be pushed to Notion with Mermaid diagram support via the /push-plan-to-notion skill, enabling seamless collaboration between AI-assisted development and project management.

Tech Stack#

  • Platform: Claude Code Plugin (TypeScript/YAML)
  • Orchestration: Multi-Agent, ReAct Pattern
  • LLM Backends: Claude, Codex, Gemini (cross-model)
  • Integration: Notion MCP, GitHub API, Jira (Atlassian MCP)
  • Protocol: Skills, Agents, Hooks (Claude Code Plugin API)
  • Distribution: Enterprise plugin marketplace
