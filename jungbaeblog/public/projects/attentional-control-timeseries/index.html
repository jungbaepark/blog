🧠 Attentional Control for Time-Series Data (Master's Thesis)

February 15, 2019

Overview#

My Master’s thesis research at KAIST exploring attentional control methods for time-series data classification and synthesis. This work investigated how attention mechanisms can improve deep learning models’ ability to process sequential data.

Research Focus#

Developed novel attention-based approaches for:

  1. Time-series Classification: Identifying patterns and categories in sequential data
  2. Time-series Synthesis: Generating realistic sequential data with desired characteristics

Key Contributions#

EEG Signal Classification#

  • Applied reinforcement learning for adaptive EEG signal processing
  • Solved the memory-based vs. memoryless trade-off problem
  • Publication: Jungbae Park, *Sang Wan Lee - “Solving the Memory-based-Memoryless Trade-off Problem for EEG Signal Classification” (IEEE SMC 2018, Oral)

Attention Mechanisms for Sequential Data#

  • Investigated how attention can focus on relevant time steps
  • Balanced model capacity with interpretability
  • Applications in neuroscience and signal processing

Tech Stack#

  • Deep Learning: LSTM, Attention mechanisms
  • Signal Processing: EEG analysis, time-series processing
  • Frameworks: TensorFlow, PyTorch

Applications#

  • Brain-Computer Interfaces (BCI)
  • Medical signal analysis
  • Sequential pattern recognition
  • Temporal data synthesis

Period#

March 2017 - February 2019

Thesis#

Title: “Attentional Control Methods for Time-series Data Classification and Synthesis” Advisor: Prof. Sang Wan Lee Institution: KAIST, Lab for Brain & Machine Intelligence

Impact#

This foundational research in attention mechanisms laid the groundwork for my later work in multimodal AI and sequential modeling, including knowledge tracing and recommendation systems.
