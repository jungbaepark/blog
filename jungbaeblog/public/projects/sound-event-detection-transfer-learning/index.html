🔊 Polyphonic Sound Event Detection with Transfer Learning

April 15, 2019

Overview#

Research on detecting multiple simultaneous sound events using convolutional bidirectional LSTMs and synthetic data-based transfer learning. This work addressed the challenge of learning from limited real-world audio data.

Key Innovation#

Synthetic Data-Based Transfer Learning:

  • Generated synthetic audio data for pre-training
  • Transferred knowledge to real-world sound event detection
  • Achieved robust performance with limited labeled data

Technical Approach#

  • Architecture: Convolutional Bidirectional LSTM
  • Data Augmentation: Synthetic audio generation
  • Transfer Learning: Pre-train on synthetic data, fine-tune on real data

Publication#

Seokwon Jeong, *Jungbae Park, *Sang Wan Lee - “Polyphonic sound event detection using convolutional bidirectional LSTM and Synthetic data-based transfer learning” (ICASSP 2019)

ICASSP: Top conference on audio & signal processing

Patents#

Multiple registered patents on sound event detection model training:

  • Method and Apparatus for Training Sound Event Detection Model (KR 1021724750000 and others)

Applications#

  • Smart home audio monitoring
  • Surveillance systems
  • Multimedia content analysis
  • Environmental sound recognition

Period#

2018 - 2019

Impact#

This work demonstrated how synthetic data could effectively address the scarcity of labeled real-world audio data, a principle applicable to many audio and speech processing tasks.
