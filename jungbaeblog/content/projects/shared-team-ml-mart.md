## Overview

At **Bucketplace (오늘의집)**, improved data quality monitoring by implementing client-side log validation and log anomaly detection notifications.

## Key Achievements

- Implemented client-side log validation
- Built log anomaly detection notifications

## Technical Approach

- **Client-Side Log Validation**: Validation applied at the log ingestion layer to catch data quality issues before they enter the pipeline
- **Log Anomaly Detection Notifications**: Automated alerting for log anomalies, enabling the team to detect and respond to data quality issues proactively

## Tech Stack

- **Data Processing**: PySpark
- **Data Warehouse**: HiveDB
